# Temporal network summary

## Current construction

The project currently builds two monthly snapshot networks from the audited
IPUMS-CPS observations:

1. `occupation_only`: excludes `OCC = 0000`.
2. `with_0000`: includes `0000` as a labelled `Not in universe` state.

Both use the same deduplicated observations and the same temporal rule. A link
exists when the same `CPSIDP` appears in exactly consecutive calendar months
with nonblank occupation/state values. Missing months do not create links.

For each month `t`, node size is the unweighted observed share:

```text
node_share(i, t) = observations(i, t) / all retained observations(t)
```

For each link from month `t` to `t+1`, the edge stores both its count and its
conditional empirical probability:

```text
transition_probability(i -> j, t)
  = count(i -> j, t) / all outgoing links from i at t
```

No visual threshold is applied to the exported data. Thresholding belongs to
visualisation and sensitivity analysis, not data construction.

The dependency-free visualisation is generated by
`scripts/create_network_visualisation.py` and written locally to
`Data/IPUM/dynamic_networks/visualisations/temporal_networks.html`. It provides
play/pause, month selection, a visual edge threshold, variant selection, and
hoverable node/edge details. The threshold changes display only; it does not
modify the exported network data.

NetworkX/Matplotlib GIFs are generated by
`scripts/create_network_animation.py`. They use a stable aggregate spring
layout across all months, so movement in the animation reflects changes in
nodes and edges rather than a changing layout. The current display threshold
is 0.01 and the full edge tables remain the source data.

## Current audited values

The occupation-only audit found 1,643,075 valid links and 124,097 changed-
occupation events. The state-inclusive audit found 3,473,375 valid links and
257,183 changed-state events. These are unweighted sample counts.

October 2025 is missing. The outputs do not interpolate it or create a
September-to-November monthly link.

## Later realism upgrades

- add CPS survey weights for population-estimated node sizes;
- validate `CPSIDP` links using demographic consistency or `CPSIDV`;
- add `EMPSTAT` and `LABFORCE` to distinguish unemployment and labour-force
  states from `0000`;
- test variable-length links separately rather than mixing them with monthly
  links;
- check occupation-code comparability and missingness over time;
- compare the two network variants and test visualisation thresholds;
- only then consider an ABM or policy simulation.
