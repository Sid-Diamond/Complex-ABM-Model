# Task Template

Use for large, ambiguous, or file-changing tasks. For exploratory work, replace
the outcome with the question or hunch being investigated.

```markdown
## Outcome or question
[What result or exploratory question do I want, and why?]

## Status
[Exploration, proposal, or decision]

## Scope
[What may change? What is out of scope?]

## Context
[Relevant files, documents, errors, or references]

## Acceptance criteria
[How will we know it is complete?]

## Verification
[Test, command, experiment, inspection, or review]

## Permission boundary
[May Codex edit, run tools, commit, or push?]
```
